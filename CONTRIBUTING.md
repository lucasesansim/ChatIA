# Contribuir

Usá Python 3.11+, un entorno virtual y una rama propia. Instalá con
`python -m pip install -e .` y ejecutá
`python -m unittest discover -s tests -v` antes de enviar un cambio.

No agregues credenciales, números reales, grabaciones, conversaciones ni sesiones.
Usá servicios simulados en las pruebas. Mantené el envío como una acción explícita
y no agregues reintentos automáticos de mensajes.

Para reportar un error, indicá sistema operativo, versión y pasos reproducibles
sin datos personales. Para una vulnerabilidad, seguí SECURITY.md.
